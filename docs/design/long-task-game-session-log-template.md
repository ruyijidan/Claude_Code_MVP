# Long Task Game Session Log Template / 长任务小游戏会话日志模板

## Purpose / 目的

Use this template to prove that a long-task mini-game run actually sustained
the requested duration.

If a run claims to satisfy a `30 minute` or `600 second` target, this log
should exist and should show the time evidence.

## Copy-Paste Template / 可直接复制的模板

```text
Long Task Game Session Log

Target duration:
- requested:
- planned start:
- planned end:

Observed run:
- actual start:
- actual end:
- elapsed:
- provider or execution path:

Artifact:
- target game:
- artifact path:
- run mode:
- difficulty:

Verification:
- commands run:
- result:
- notes:

Outcome:
- sustained target duration: yes/no
- major upgrades made:
- whether the run preserved or replaced an artifact:
```

## Required Evidence / 必要证据

At minimum, the log should include:

- requested duration
- actual start time
- actual end time
- elapsed time
- the artifact path
- the verification command and result

If the run did not actually reach the requested duration, say so plainly.
